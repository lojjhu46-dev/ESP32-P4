## 目标

修 4 个模拟器 UI 问题，**只动 PC 模拟器侧的 LVGL UI**（已核实 `ui_shared.c` 没有被 `jc_p4_app/main` 引用，板端固件零改动、无需重烧）：

文件：`lvgl_project/lv_port_pc_vscode_official/main/src/ui_shared.c`（可选 +1 行 `main/src/main.c`）

## 根因（已读源码逐条定位，不是猜测）

| # | 现象 | 根因 |
|---|---|---|
| 1 | 键盘点不动 | `lv_keyboard_create(lv_screen_active())`（ui_shared.c:514）把键盘建在**屏幕层**；而 `lv_msgbox_create(NULL)` 会在 `lv_layer_top()` 上自动建一个 **100%×100% 背板**（lv_msgbox.c:117-121）。`lv_obj` 默认带 `LV_OBJ_FLAG_CLICKABLE`（lv_obj.c:167）→ 这块全屏背板在最上层吞掉所有点击，键盘（和下面的主 UI）全部失效 |
| 2 | 空输入点 OK 也"成功" | `input_ok_cb` 只判 `name && name[0]`（ui_shared.c:409），无论是否为空都会落到第 443 行 `close_input()` —— 空输入静默关窗，看起来像成功 |
| 3 | "1 / 3 / 5" 含义不明 | shots 按钮直接写裸数字（ui_shared.c:484 `{"1","3","5"}`），没有说明它们 = 注册采集帧数 |
| 4 | 关闭弹窗后主 UI 被透明层盖住、点不动 | `close_input()` 用 `lv_obj_delete(s_ui.mbox)`（ui_shared.c:379），但背板是 mbox 的**父对象**；只有 `lv_msgbox_close()` 才会连父背板一起删（lv_msgbox.c:284-288）→ 那块 50% 灰、可点击的全屏遮罩永久留在 `lv_layer_top()` 上 |

## 改动（ui_shared.c）

1. **`close_input()`**：`lv_obj_delete(s_ui.mbox)` → **`lv_msgbox_close(s_ui.mbox)`**（连自动背板一起删），并把 `ta_name / row_shots / lbl_prog / bar_prog / btn_ok / btn_cancel` 全部置 NULL（现在这些指针关窗后仍指向已删对象）。
2. **`open_input()`**：键盘父对象改 **`lv_layer_top()`** 并 `lv_obj_move_foreground(kb)`（替掉现在对 mbox 的 foreground 调用）——与背板同层且在它之后创建，点击与绘制都在遮罩之上。对话框仍居中，480x800 下与底部 240px 键盘不重叠。
3. **OK 置灰（按你的选择）**：`open_input()` 里 OK 初始 `lv_obj_add_state(ok, LV_STATE_DISABLED)`；给输入框加 `LV_EVENT_VALUE_CHANGED` 回调，内容为空/纯空格 → 置灰，有内容 → 解除。同时把 OK 逻辑抽成 `do_input_ok(cmd, ta)`，开头再挡一道空白（防止其他路径绕过），**不加长度/字符限制**。
4. **shots 行文案**：加英文标题 `Shots:`，后面保留 1 / 3 / 5 数字按钮（行宽改 100%、按钮 50x30、列间距 6，保证放得下），默认 3 高亮逻辑不变。
5. **顺带**（1 行，模拟器 `main.c`）：鼠标光标对象从 `lv_screen_active()` 改到 `lv_layer_sys()`，否则弹窗期间指针被遮罩压暗。
6. **顺带**（小重构收益）：键盘右下 ✓ 键（`LV_EVENT_READY`）接到与 OK 同一条路径（需要上面 `do_input_ok` 的抽取，否则现在会把键盘当 target 取出 NULL cmd 而崩）；顺带让目前只写不读的 `s_ui.reg_cmd` 真正派上用场。

## 不改什么

- 板端固件（`app_faceai.cpp` 等）零改动；发给板端的命令格式 `{"cmd":"register","id":...,"shots":N}` 与 shots 语义不变。
- ⚠️ 记录一个**既有**隐患（本次按你的选择不修）：`char js[160]`（ui_shared.c:410）遇到超长名字会被 `snprintf` 截断 → 发出残缺 JSON；将来想堵只需 `lv_textarea_set_max_length(ta, UI_NAME_MAX-1)` 一行。
