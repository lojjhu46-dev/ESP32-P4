# JC-ESP32P4-M3-DEV 项目框架构建指南

> 适用环境：Windows + ESP-IDF v5.5.x（本机：`D:\ESP-IDF\v5.5.5\esp-idf`，EIM 安装，激活脚本 `C:\Espressif\tools\Microsoft.v5.5.5.PowerShell_profile.ps1`）
> 硬件：Guition JC-ESP32P4-M3-DEV（ESP32-P4 + ESP32-C6，32MB PSRAM / 16MB Flash）
> 引脚依据：《JC-ESP32P4-M3-DEV-开发要点.md》

---

## 1. 环境准备

```powershell
# 每个新终端先激活 IDF 环境
. C:\Espressif\tools\Microsoft.v5.5.5.PowerShell_profile.ps1
idf.py --version    # 确认 v5.5.x
```

硬件连接：USB 线接 **CH340C 串口座**（USB-TTL），装好 CH340 驱动，供电 ≥500mA。设备管理器确认 COM 口。

## 2. 创建工程

```powershell
cd D:\esp32project\ESP32-P4
idf.py create-project my_project
cd my_project
```

> 更省事的做法：直接复制 `D:\esp32project\ESP32-P4\C3982-JC-ESP32P4-M3-DEV\...\1-Demo\IDF-DEMO\NoDisplay\wifi_scan`（无屏项目）或 `withDisplay\test`（带屏项目）为模板，删除其中 `build/` 目录后改名使用——两者的 sdkconfig 与组件依赖均已验证可跑。

```

```

## 4. 引脚定义头文件 `components/board_pins.h`

```c
#pragma once
#include "driver/gpio.h"

/* ---- I2C（总线1，挂 GT911/ES8311/ES7210/背光0x45/摄像头SCCB）---- */
#define PIN_I2C_SDA      GPIO_NUM_7
#define PIN_I2C_SCL      GPIO_NUM_8
#define I2C_BUS_NUM      1          // demo 统一用 I2C_NUM_1

/* ---- 音频 I2S0 ---- */
#define PIN_I2S_MCLK     GPIO_NUM_13
#define PIN_I2S_SCLK     GPIO_NUM_12
#define PIN_I2S_LRCK     GPIO_NUM_10
#define PIN_I2S_DOUT     GPIO_NUM_9    // P4 -> ES8311
#define PIN_I2S_DIN      GPIO_NUM_48   // ES7210 -> P4
#define PIN_PA_CTRL      GPIO_NUM_11   // NS4150 功放使能

/* ---- 以太网 RMII (IP101GRI) ---- */
#define PIN_RMII_TXD0    GPIO_NUM_34
#define PIN_RMII_TXD1    GPIO_NUM_35   // 兼 BOOT 脚
#define PIN_RMII_TXEN    GPIO_NUM_49
#define PIN_RMII_RXD0    GPIO_NUM_29
#define PIN_RMII_RXD1    GPIO_NUM_30
#define PIN_RMII_RXDV    GPIO_NUM_28
#define PIN_MDC          GPIO_NUM_31
#define PIN_MDIO         GPIO_NUM_52
#define PIN_PHY_RST      GPIO_NUM_51

/* ---- TF 卡（SDMMC slot1 默认引脚，勿改）---- */
#define PIN_SD_CLK       GPIO_NUM_43
#define PIN_SD_CMD       GPIO_NUM_44
#define PIN_SD_D0        GPIO_NUM_39
#define PIN_SD_D1        GPIO_NUM_40
#define PIN_SD_D2        GPIO_NUM_41
#define PIN_SD_D3        GPIO_NUM_42

/* ---- RS485 (UART1) ---- */
#define PIN_RS485_TXD     GPIO_NUM_26
#define PIN_RS485_RXD     GPIO_NUM_27

/* ---- P4 <-> C6 ---- */
#define PIN_C6_SDIO_CMD  GPIO_NUM_19
#define PIN_C6_SDIO_CLK  GPIO_NUM_18
#define PIN_C6_SDIO_D0   GPIO_NUM_14   // D1=15 D2=16 D3=17
#define PIN_C6_RESET     GPIO_NUM_54   // C6_CHIP_PU，高有效
#define PIN_C6_BOOT      GPIO_NUM_6

/* ---- 其他 ---- */
#define PIN_BAT_ADC      GPIO_NUM_53   // ADC2_CH4
#define PIN_TOUCH_INT    GPIO_NUM_20    // 预留
#define PIN_TOUCH_RST    GPIO_NUM_21    // 预留
#define PIN_LCD_PWM      GPIO_NUM_23    // 预留（DSI 屏背光实际走 I2C 0x45）
/* LCD_RST / 背光 PWM 不接 GPIO；BOOT=35, RST=CHIP_PU */
```

## 6. 各外设初始化模板

### 6.1 I2C 总线（最先初始化，其他模块复用句柄）

```c
#include "driver/i2c_master.h"
static i2c_master_bus_handle_t i2c_bus;

void app_i2c_init(void) {
    i2c_master_bus_config_t cfg = {
        .i2c_port = I2C_BUS_NUM,
        .sda_io_num = PIN_I2C_SDA,
        .scl_io_num = PIN_I2C_SCL,
        .clk_source = I2C_CLK_SRC_DEFAULT,
        .glitch_ignore_cnt = 7,
        .flags.enable_internal_pullup = 0,   // 板上有 2.2K/5.1K 上拉
    };
    ESP_ERROR_CHECK(i2c_new_master_bus(&cfg, &i2c_bus));
}
```

### 6.2 显示（MIPI-DSI + JD9365，800×1280）

1. 从 `1-Demo\ARDUINO-DEMO\jc_esp32p4_m3_lvgl_v8\src\lcd\` 拷贝 `esp_lcd_jd9365_10_1.c/h`（它是 IDF 组件写法，去 Arduino 依赖即可）放入 `components/esp_lcd_jd9365_10_1/`。
2. 初始化顺序（参考 `jd9365_lcd.cpp::begin()`）：

```c
#include "esp_ldo_regulator.h"
#include "esp_lcd_mipi_dsi.h"
#include "esp_lcd_jd9365_10_1.h"

void app_display_init(void) {
    /* 1. DSI PHY 供电：内部 LDO VO3 = 2.5V（必须先做）*/
    esp_ldo_channel_handle_t ldo;
    esp_ldo_channel_config_t ldo_cfg = { .chan_id = 3, .voltage_mv = 2500 };
    ESP_ERROR_CHECK(esp_ldo_acquire_channel(&ldo_cfg, &ldo));

    /* 2. 建 DSI 总线（2 lane）+ DBI io + JD9365 面板 */
    esp_lcd_dsi_bus_config_t bus = JD9365_PANEL_BUS_DSI_2CH_CONFIG();
    esp_lcd_dbi_io_config_t dbi  = JD9365_PANEL_IO_DBI_CONFIG();
    esp_lcd_dpi_panel_config_t dpi = JD9365_800_1280_PANEL_60HZ_DPI_CONFIG(LCD_COLOR_PIXEL_FORMAT_RGB565);
    jd9365_vendor_config_t vendor = {
        .mipi_config = { .dsi_bus = bus_hdl, .dpi_config = &dpi, .lane_num = 2 },
        .flags.use_mipi_interface = 1,
    };
    // esp_lcd_new_dsi_bus / esp_lcd_new_panel_io_dbi / esp_lcd_new_panel_jd9365 ...
    /* 3. 背光：I2C 总线 1 写 0x45 寄存器 0x96（0~255）*/
}
```

### 6.5 音频（ES8311 播放 + ES7210 采集）

- I2S 标准模式：MCLK=13、BCLK=12、WS=10、DOUT=9、DIN=48（`i2s_std`）
- codec 经 `esp_codec_dev` 组件配置（ES8311 0x18 / ES7210 0x40~0x43）
- PA 使能：`gpio_set_direction(PIN_PA_CTRL, GPIO_MODE_OUTPUT)` 后拉高
- 现成封装：`withDisplay/common_components/bsp_extra/`（`bsp_extra_codec_init/volume_set/i2s_read/i2s_write`），直接拷入 `components/`
- Demo：`NoDisplay/mp3_player`

## 7. 编译、烧录、调试

```powershell
idf.py set-target esp32p4        # 仅首次
idf.py build
idf.py -p COMx flash monitor    # COMx = CH340 端口
# 退出 monitor：Ctrl+]
idf.py menuconfig                # 改配置
idf.py fullclean                 # 配置错乱时重来
```

- 下载失败：按住 BOOT(GPIO35) 再按 RST 进强制下载模式（CH340 的 DTR/RTS 一般可自动进入）
- 量产/恢复出厂固件：`flash_download_tool`，ESP32-P4 / UART 模式，`JC-ESP32P4-M3-DEV-TEST-V1.3.bin` @ 0x0，QIO 80MHz

## 8. 常见坑清单

| 坑 | 说明 |
|---|---|
| GPIO35 双职能 | 既是 BOOT 又是 RMII_TXD1；启动瞬间勿被外设拉低 |
| GPIO26/27 已占用 | RS485 专用，勿挪作他途 |
| DSI PHY 无电黑屏 | 初始化顺序：先 `esp_ldo_acquire_channel(3, 2500)` 再建 DSI 总线 |
| 背光不亮 | 背光不走 PWM 引脚，必须 I2C 写 0x45/0x96 |
| Wi-Fi 报 esp_wifi_remote 缺失 | `idf_component.yml` 加 `espressif/esp_wifi_remote`；C6 无响应先查 GPIO54 复位 |
| PSRAM 相关崩溃 | 确认 `SPIRAM_SPEED_200M`；LVGL 缓冲可用 PSRAM（`MALLOC_CAP_SPIRAM`），DMA 缓冲必须内部 RAM |
| TF 卡不识别 | mount 前用 `esp_ldo_acquire_channel(4, 3300)` 打开卡电源 |
| 触摸无响应 | GT911 在 I2C 总线 1（GPIO7/8），确认总线已初始化、地址尝试 0x5D/0x14 |
| IDF/Python 环境 | 勿把普通 pip 包装进 IDF 环境；普通终端与 IDF venv 隔离（见既有环境约定） |

## 9. 快速起步路线建议

1. **跑通模板**：复制 `wifi_scan` → 编译烧录 → 确认能扫到 AP（验证工具链 + C6 链路）
2. **点亮屏幕**：引入 JD9365 组件 + I2C1 → 画纯色 → GT911 读坐标 → 接入 LVGL
3. **加业务模块**：按 6.5~6.7 按需叠加（每模块独立 `app_xxx.c`，统一由 `main.c` 调度）
4. **进阶**：参考 `xiaozhi-esp32`（本板完整 AI 语音项目，含 P4 配置）做应用层架构设计
